# 👤 Face Detection System using Python, OpenCV & dlib

A real-time Face Detection System developed using Python, OpenCV, and dlib. The project demonstrates multiple face detection techniques, including HOG-based detection, CNN-based detection, and SSD deep learning models for accurate face localization in images and live video streams.

---

## 📌 Features

-  Real-time face detection using webcam
-  Face detection in static images
-  Multiple detection methods:
  - HOG + SVM
  - CNN (dlib)
  - SSD Deep Learning (OpenCV DNN)
-  High-performance face localization
-  Pre-trained deep learning models
-  Comparison of different face detection approaches
-  Easy-to-run Python implementation

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/SakinaMuzzammil/face-detection.git
```

### Navigate to the project

```bash
cd face-detection
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run any implementation

```bash
python face_detection_hog_svm.py
```

or

```bash
python face_detection_cnn.py
```

or

```bash
python face_detection_ssd.py
```
